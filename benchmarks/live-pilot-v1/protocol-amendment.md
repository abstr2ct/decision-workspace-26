The sealed protocol remains unchanged. Its input hashes describe LF-normalized text; Windows write_text produced CRLF bytes. retry-input-manifest.json records actual raw SHA256. retry-material-verification.json verifies identical raw bytes for all six retry stage1 packets. This corrects encoding metadata, not task content. Stage2 uses the first COMPLETED retry pair because original attempts were interrupted. Timing is first worker timestamp to completion, not dispatch latency (measurement-notes.md).
