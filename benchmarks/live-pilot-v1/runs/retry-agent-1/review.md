# Отдельный проверочный проход LLM

Проверены report.md, authored/research.json, authored/options.json и расчёты; источники сверены через CLI source show и исходные переданные строки. Это самопроверка другим проходом той же LLM, не независимый эксперт и не новый источник.

- Высокая значимость, research/findings[0]: первая версия связывала числовой вывод с UX claim. Исправлено на cohort-summary, который цитирует производный cohort-metrics, наследующий synthetic от cohorts. Детальное межмесячное разложение остаётся в calculate.py и calculations.json, ссылка на исходные строки есть в отчёте.
- Высокая значимость, experiment: срок 14 дней не позволяет D30. Исправлено разделением диагностики и будущего теста; 704 аккаунта, оптимистичный календарь 282 дня. Для вмешательства до активации требуется иной знаменатель, явно указано.
- Высокая значимость, communication: roadmap, гарантии и «любая команда» не поддержаны. Заменены ручным сценарием, предупреждениями и ограничением до 20 сотрудников.
- Средняя значимость, economics: вклад не прибыль; добавлены постоянные расходы, ограничение календарного сопоставления, отсутствие повторной выручки и стоимости выхода.
- Средняя значимость, варианты: рассмотрены цена закрытия, два возражения каждому варианту и развилки без необоснованных весов. Числовая decision-lab не применяется: общей защищаемой шкалы полезности нет.
- Ограничение пилота: 8 наблюдений не дают мощности; если одни участники проверяют оба сценария, возможен перенос обучения. Случайный порядок уменьшает, но не устраняет его. Порог 6/8 — предложенный критерий осуществимости, не статистическое доказательство.
- Не разрешены: происхождение падения активации, реальные каналы, LTV, расходы реализации/выхода, тарифы среды. Эти пробелы могут изменить выбор.

CLI audit: не пройден для финального утверждённого результата — отсутствуют одобрение decision и committed strategy. Это правильная граница полномочий, не дефект, скрытый фиктивным согласованием. Экспорт выполнен только --draft. Отчёт является проектом стратегии вне стадийного commit. Внешних действий не было.

Сбой propose в workflow.py: список claims ошибочно передан одной строкой с запятыми. Зависимый шаг остановлен, восстановлен через finish_workflow.py с отдельными аргументами; журнал сохранён. State вручную не редактировался.
