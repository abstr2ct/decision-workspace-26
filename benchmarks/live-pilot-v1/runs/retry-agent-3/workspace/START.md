# Первый запрос агенту

Открой эту папку в IDE с LLM. Убедись, что среда умеет читать файлы и запускать Python. Вставь в чат:

> Прочитай AGENTS.md. Работай как Стратег Фабрики продуктов. Создай проект `projects/my-product`. Мой вопрос: «[вставить запрос]». Разрешённые материалы: [пути/домены]. Ограничения: [что известно]. Сначала кратко сформулируй решение, которое предстоит принять, и задай только один вопрос, важный для следующего шага. Затем веди процесс сам; при выборе варианта покажи основания и дождись моего решения. Не запускай учебный replay вместо исследования.

Для продолжения в новом чате:

> Прочитай AGENTS.md и выполни `python -m strategist resume projects/my-product`. Продолжи с сохранённого места. Если требуется мой существенный выбор, покажи варианты и основания. Историю чата не восстанавливай догадками.

Для новых данных:

> В `projects/my-product` появился материал [путь/URL]. Проверь его влияние на прежние выводы через skill decision-revision. Сохрани исходные основания и покажи, что требует пересмотра. Не считай новую информацию автоматически истинной.

Для остановки:

> Сохрани сделанное, зафиксируй ближайший шаг и приостанови проект. Не продолжай исследование до моего указания.

Для проверки хрупкости выбора:

> Покажи, какое правдоподобное наблюдение заставит изменить рекомендацию. Используй skill decision-lab, если есть обоснованная общая шкала; иначе сравни развилки качественно. Не придумывай вероятности или денежный эффект. Учти стоимость проверки, задержку и возможный неубедительный результат. Сначала опровергни самое слабое допущение собственной рекомендации.
