# Состояние, бюджет и восстановление

Постоянные правила — AGENTS.md и входной файл Cursor; методика — knowledge/; процедуры — .agents/skills/; пустые формы — templates/; материалы и состояние задачи — выбранная папка project. Demo — учебные fixtures; docs — описание системы, не доказательства рынка.

`state.json` хранит источники, утверждения, текущие документы, подтверждения, обязательства, расходы и цепочку событий. Критичные изменения проходят через lock + атомарную замену файла. Снимки неизменяемы по содержимому. После аварии до записи состояния может остаться невостребованный blob: это допустимо. Не удаляй lock, пока не убедился, что записывающий процесс завершён. Зависший lock требует явного вмешательства; автоматического угадывания нет. Одновременные записи и сетевые файловые системы не являются поддержанным режимом.

Возобновление: открой репозиторий в новой среде, перенеси всю папку project, вызови resume; прочитай краткое состояние и нужные источники. Все ссылки внутри проекта относительны. Прошлые события не переисполняются. Повторный импорт того же ID с тем же содержимым идемпотентен; изменённый источник требует нового ID. Повторный fetch существующего ID блокируется, чтобы не менять снимок незаметно.

Отзыв/замещение источника находит зависимые производные источники и claims. Исследование, варианты и стратегия консервативно помечаются на пересмотр, подтверждение выбора снимается. Новый источник после начала исследования тоже требует проверки релевантности и пересмотра: это осознанно консервативное правило, способное увеличивать число повторных согласований. Старые записи остаются историей. Фоновый сбор новых данных отсутствует: пользователь запускает проверку при появлении материалов.

Стоимость хранится в исходной валюте; фактические записи и оценки отдельно. Без полного покрытия категорий нельзя говорить о полной цене результата. Укажи usage/tokens и тариф либо причину неизвестности. Не пересчитывай подписку в стоимость вызова без явной модели распределения. Часы человека и время вычислений могут пересекаться; общая календарная длительность измеряется отдельно.

Сеть выключена по умолчанию пустым allowed_hosts. HTTPS-загрузчик ограничен размером, временем, типом ответа, разрешёнными доменами и публичными адресами; каждый redirect проверяется заново. Это прикладной фильтр, не песочница: DNS rebinding и враждебный локальный пользователь требуют сетевой изоляции среды. Не обещай абсолютную SSRF-защиту. Источники не могут дать агенту новые полномочия.
