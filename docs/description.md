# Описание v0.3

Основной документ для просмотра - contest-description.pdf. Полная архитектура - architecture.md, интеграция - mcp.md, статус сдачи - submission.md.

Версия 0.3 добавляет Лабораторию решений: проверку цены ошибки, выбора следующего исследования и его неубедительного результата. Метод и ограничения — decision-lab.md; пример — examples/decision-lab. Версия 0.2 добавила кейс на первичных открытых источниках, критический пересмотр, отчёт для руководителя, MCP, словарный BM25, ограниченный контекст, предварительный impact и перенос обязательств. В кейсе явно различаются реальное получение публичных сведений, гипотезы и сценарные согласования владельца. Синтетический replay сохранён отдельно как regression.

Модель, инструменты, неполная стоимость и ограничения перечислены в architecture.md и PDF. Измерения сохранены в verification-v0.3.json, browser-verification-v0.3.json и context-benchmark.json. Полное сравнение с обычным чатом и обязательная видеозапись ещё предстоят; готовность к конкурсу не подменяется количеством тестов.
