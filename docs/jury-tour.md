# Проверка для жюри за 90 секунд

1. Откройте [разбор пилота](../examples/telecom-brief/demo-run/review.html). Сравните +3,05 п.п. по известным исходам и диапазон по всем назначенным семьям. Посмотрите, почему первым шагом стала сверка.
2. Откройте карточку после сверки и раскройте «Проверяемые основания». Производный расчёт ссылается на тот же план и исправленный срез. Старые данные доступны в истории.
3. Из корня распакованного репозитория повторите прогон в новой папке. В журнале увидите решение Q1, состояние паузы, восстановление, отказ выпуска старой карточки и предложение Q2.

```text
python -X utf8 examples/telecom-brief/replay.py projects/family
```

Откройте `projects/family/review.html`. Для запуска нужен Python 3.10+ без установки пакетов. Для живой задачи используйте START.md в IDE с LLM.

[Стратегия по брифу](../examples/telecom-brief/strategy.md) включает исходные данные, альтернативы, пути клиента, прогноз и план по кварталам. [Другой сценарий выбора](../examples/decision-lab/exports/decision-lab.html) показывает, при каких исходах исследования оно может оказаться полезным.
