# Что улучшено относительно 0.1

| Критерий | Было | Стало |
| --- | --- | --- |
| Проработанность | Синтетический кейс и заранее подготовленные fixtures | Отдельный кейс на первичных открытых источниках, явное расхождение условий, ограничения спроса/экономики, критический обзор и пересмотр против дублирования уже существующей функции |
| Масштаб нейротехнологий | Поиск слов и advisory routing | Билингвальный BM25 с понятийным расширением и связями, ограниченный контекст с явными пропусками, read-only MCP stdio с реальным roundtrip |
| Имплементация | 34 теста, цитаты, состояния и перерыв | 49 тестов, защита относительных путей, соответствие одобрения событию, контроль синтетической родословной, обнаружение Client Challenge и перенос обязательства с историей |
| Качество | Технический Markdown | Отчёт для руководителя с обзором/вкладками/фильтрами, мобильная версия, реальные скриншоты и PDF; после доработки дизайна - 8 страниц. Измеряется объём начального контекста вместо неподтверждённых заявлений об экономии |

Сохранены сильные стороны первой версии: автономный выбор шагов моделью в IDE, два навыка, раздельные слои знаний, воспроизводимая арифметика, статусы утверждений, атомарность, переносимость и сценарное тестирование пересмотра.

Не заявляются как реализованные: независимая экспертиза, автоматическое переключение LLM, embeddings, фоновый наблюдатель, мультимодальное извлечение и полный baseline benchmark. Исторический статус v0.2: видеозапись и публикация ещё не выполнены. Актуальный план без ожидания демобрифа — docs/submission.md.
