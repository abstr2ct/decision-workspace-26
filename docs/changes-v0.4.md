# Версия 0.4

Добавлен воспроизводимый разбор изменения D30 между двумя зрелыми когортами: изменение показателей внутри сегментов и изменение состава аудитории. Метод останавливается при отсутствующих сегментах, незрелости или нулевом знаменателе. Результат хранится как производный источник с обычным отзывом оснований. Методика и ограничения: cohort-comparison.md.

Сравнительный стенд создан на новом учебном продукте «Смена». Протокол фиксируется до запусков; исходники, отчёты, измерения и попытки с ошибками сохраняются. Замороженная версия эксперимента — v0.3. Новая команда анализа в эти прогоны не добавляется. Сравнение не подменяет независимую человеческую оценку и не даёт общего вывода о превосходстве на других задачах.

Скрипт compare_runs теперь сохраняет неизвестное время человека как null вместо требования подставить число. Это исключает ложный вывод о нулевых трудозатратах.

По уточнению организаторов, переданному пользователем 14 ноября: демонстрационный бриф — дополнительный материал; проект должен работать самостоятельно. Ориентир публикации — понедельник-вторник. Дальнейшая работа над проектом не зависит от этого срока.
