# Из чего складывается изменение удержания

Общая D30 может снижаться, даже когда она растёт внутри каждого сегмента. Новый инструмент сравнивает два зрелых cohort-ID в одном CSV и явно показывает влияние смены состава. Это полезная проверка перед решением переделать onboarding или увеличить рекламный бюджет.

```text
python -m strategist analyze-cohorts projects/case --source cohorts --id period-comparison --compare 2026-08 2026-09
```

Требуются одинаковые сегменты, положительные activated и matured_d30=true во всех строках выбранных когорт. Остальные строки тоже проверяются на корректность; незрелые строки явно перечислены. Метаданные источника должны подтверждать одинаковое окно наблюдения и определения сегментов.

Для каждой группы r означает retained/activated, w — долю activated этой группы. Разложение задаёт конкретный порядок:

```text
изменение внутри сегментов = сумма w_старое × (r_новое − r_старое)
изменение состава = сумма (w_новое − w_старое) × r_новое
сумма двух частей = новая общая D30 − старая общая D30
```

Внутренняя проверка тождества использует точные рациональные числа. Вывод — доли и процентные пункты. Выбор порядка влияет на распределение взаимодействия факторов: здесь оно входит в компонент состава. Это описательный расчёт, не причинная модель и не тест статистической значимости.

В новом учебном примере общая D30 меняется 52% → 33%, а при прежнем составе была бы 57%. Разложение: +5 п.п. внутри сегментов и −24 п.п. за счёт состава. После исправления входной строки общая D30 равна 25%, внутрисегментная часть −27 п.п., часть состава 0 п.п. Это показывает, почему нужны повторный расчёт и пересмотр объяснения после новых данных.

Возможность добавлена ПОСЛЕ фиксации сравнительного протокола. Замороженный агент v0.3 в эксперименте её не имеет. Результаты того сравнения не доказывают преимущество новой команды; её арифметика проверяется отдельными тестами.
