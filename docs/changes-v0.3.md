# Версия 0.3 — стратегия, которую можно опровергнуть

| Критерий | Усиление | Проверяемый результат |
| --- | --- | --- |
| Проработанность | Сценарии с условиями опровержения, цена отказа и ошибочного выбора, жёсткие ограничения, критика диагностики | В учебном кейсе более слабое допущение о качестве исследования меняет вывод о его гарантированной пользе |
| Нейротехнологии | Повторяемый skill: LLM формулирует развилки, выбирает инструмент, критикует допущения; Python выполняет арифметику; MCP отдаёт результат | Третий skill, седьмой read-only MCP tool; нет новых API, моделей, подписок или автономного runtime |
| Имплементация | Analysis → commit → resume → invalidation → redecision, идемпотентность и хеши | Проверки сохранённого анализа, новый процесс, stale export, HTML escaping и независимый перебор математических политик |
| Качество | Читаемая лаборатория, проверка за 90 секунд, явные расходы и остановка ненужной проверки | Локальный интерактивный HTML и обновлённый PDF; ограничение цены ошибки отделено от реального эффекта бизнеса |

Лаборатория не объявляется новым научным методом. Отличие решения — в связке агентного исследования, условной модели выбора, критики качества следующего наблюдения и проверяемой памяти. Входные допущения остаются предметом экспертизы; расчёт не спасает плохую постановку задачи.

Демобриф не является зависимостью завершения. Используем собственные иллюстративные кейсы в рамках предоставленного задания. Обязательная видеозапись работы LLM, публикация и независимая оценка по-прежнему не заменяются подготовленными примерами.
