# Кейс на открытых источниках

Этот кейс подготовлен в текущей сессии LLM: открыты и сопоставлены первичные страницы, выявлено расхождение платформенных условий, сформированы варианты и условная стратегия. Это не заранее существовавший fixture синтетической аналитики.

Согласования владельца - явно сценарные. Реальный продукт и данные пользователей не изменялись. Достоверность спроса, причинного эффекта и экономики не заявляется. Полные страницы не перепубликуются: сохранены короткие проверенные выдержки, URL и контрольные суммы полученных ответов.

Откройте `exports/dashboard.html` или `exports/strategy.md`. Состав источников и время получения - `exports/source-acquisition.json`. Полная цена исследования неизвестна; записано только локальное техническое время. Нельзя выдавать этот пример за официальный демобриф конкурса или независимый live-eval другой модели.
