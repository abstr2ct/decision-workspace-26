# Карточка решения владельца

Исходное состояние — checkpoint завершённого живого прогона frozen v0.3 на новой синтетической задаче «Смена». Карточка создана инструментом v0.5 из этих сохранённых данных; новый модельный прогон не выполнялся. Бизнес-решение не одобрено, все материалы учебные. Это пример удобной выдачи и сохранения границы согласования.

Откройте exports/decision-card.html. Источники раскрываются по локальным ссылкам. Карточка не генерирует новую стратегию и не подтверждает истинность исходных допущений. После исправления источников нужно пересмотреть документы и заново создать карточку — устаревший проект её сформировать не сможет.
