# «Смена» · исправление данных меняет решение

Учебный проект на собственных синтетических материалах. Продукт «Смена» — планировщик для команд до 20 сотрудников. Руководитель видит падение D30 и предлагает переделать онбординг. Бюджет проверки ограничен 30 000 ₽, первое решение нужно принять за 14 дней.

| Этап | Материалы и результат |
| --- | --- |
| Запрос и исходные данные | [Запрос](../../benchmarks/live-pilot-v1/inputs/request.md), [когорты](../../benchmarks/live-pilot-v1/inputs/cohorts.csv), [возможности продукта](../../benchmarks/live-pilot-v1/inputs/product.md), [заметки](../../benchmarks/live-pilot-v1/inputs/notes.md) |
| Первое решение | [Полный проект стратегии](../owner-review/exports/report.md), [карточка владельца](../owner-review/exports/decision-card.html). Исследование выполнено LLM в отдельном сеансе |
| Исправление | [Записка аналитика](../../benchmarks/live-pilot-v1/inputs/correction.md), [исправленная таблица](corrected-cohorts.csv), [журнал команд](trace.json) |
| Пересмотр | [Обновлённая стратегия](report-update.md), [карточка владельца](revised/exports/decision-card.html), [черновик с источниками](revised/exports/dashboard.html) |

В первом проходе сентябрьский D30 составлял 33%, а у команд — 65%. После исправления оба показателя равны 25%. Сентябрьский вклад команд после привлечения сменился с +5 000 на −15 000 ₽. Агент снимает прежнее основание, откладывает увеличение закупок и предлагает ограничиться сверкой данных и экономики. Владелец видит новый выбор и условия, при которых стоит вернуться к диагностике.

Первый отчёт получен в изолированном сеансе Codex. Пересмотр подготовлен текущим сеансом из сохранённого проекта и поправки к данным. Полный технический проход от контрольной точки воспроизводится без модели, сети и ключей:

```text
python -X utf8 examples/shift-demo/replay-update.py projects/shift-review
```

Укажите новую папку проекта. Сценарий запускает реальные команды `resume`, `impact`, `source supersede`, `analyze-cohorts`, `checkpoint` и `decision-card` отдельными процессами. Прежняя карточка блокируется при попытке выпустить её заново. Затем создаётся новая рекомендация со статусом «на согласование».
