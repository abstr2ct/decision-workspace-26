# Лаборатория решений: собственный учебный кейс

Откройте exports/decision-lab.html. Четыре сценария меняют выбор от масштабирования до закрытия. Возврат ко всем сценариям показывает ограниченный пилот как кандидата по минимальной худшей цене ошибки.

Входы: lab-input/idealized.json и with-inconclusive.json. Во втором появляется неубедительный исход проверки: обещание гарантированной пользы больше не подтверждается. Итоги авторского replay: exports/lab-replay.json. Полная методика: ../../docs/decision-lab.md.

Все денежные значения сценариев авторские и не выведены из когорт. Исходные когорты синтетические; согласования сценарные. Это воспроизводимая демонстрация инструментов, не живое исследование LLM, не реальная проверка спроса и не официальный бриф. Сохранённая история включает предыдущие формулировки; актуальные документы получены обычным пересмотром без редактирования state.json.

Новый запуск из корня: python -X utf8 demo/lab.py projects/new-lab
