# Связь для близких и собственных устройств

[Открыть обзор демопроекта в PDF](00-Демопроект.pdf). В нём собраны запрос, обе стратегии, план пилота и пересмотр после сверки.

**Демонстрационный проект по примеру брифа МегаФона.** Откройте [результат пилота и две карточки](demo-run/review.html). В первом срезе сигнал проходит правило пользы, а финансисту нужно подтвердить экономику. После сверки у 80 семей исход неизвестен. Приоритет меняется: сохранить охват и восстановить данные.

| Шаг | Артефакт |
| --- | --- |
| Входные условия | [Выписка из примера брифа](source-notes.md) с указанием страниц и хеша оригинала |
| Стратегия Q1 | [Пять частей](strategy.md), [варианты и прогноз](forecast.json), [план пилота](pilot-plan.json) |
| Пауза и продолжение | [Проект Q1](demo-run/q1/exports/dashboard.html), [журнал CLI](demo-run/trace.json) |
| Срез Q2 | [Исходная выгрузка](observations/reported.json), [разбор до сверки](demo-run/q2-reported/exports/decision-card.html) |
| Сверка | [Записка аналитика](observations/reconciliation.md), [исправленный срез](observations/reconciled.json), [новое заключение](readout.md) |

Вымышленный оператор и все наблюдения пилота синтетические. Этапы Q1 и Q2 относятся к плановому году внутри примера. Стратегия и пересмотр подготовлены в Codex. Сценарий повторно исполняет команды по заранее подготовленным материалам. Согласования рамки и пилота Q1 сыграны. Итог Q2 ожидает решения владельца.

Для повторения из корня репозитория укажите новую папку. Python 3.10+, ключи и сеть для воспроизведения не требуются.

```text
python -X utf8 examples/telecom-brief/replay.py projects/family
python -X utf8 examples/telecom-brief/forecast.py
```

В свежем `projects/family/review.html` появится тот же сравнительный отчёт. При чтении из другой папки используйте карточки и журнал, которые лежат рядом с отчётом. Стратегия и исходные документы находятся в `examples/telecom-brief`.
