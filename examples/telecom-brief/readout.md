# Решение Q2 после сверки пилота

**Сохранить текущий охват и восстановить 80 неизвестных исходов.** Расширение не согласовано. Сигнал о низком остатке и существующее ручное выделение объёма остаются выбранным сценарием проверки на одном совместимом тарифе. Приглашение, согласие на просмотр остатка и возможность отзыва остаются обязательными условиями. Обещание клиенту ограничено доступным действием на его тарифе.

| Показатель | Первоначальный срез | После сверки |
| --- | ---: | ---: |
| Семьи в контроле / сигнале | 1 700 / 1 700 | 1 700 / 1 700 |
| Известные ограничения в контроле / сигнале | 204 / 145 | 204 / 145 |
| Неизвестные исходы в сигнале | 0 | 80 |
| Разница только по известным исходам | +3,47 п.п. | +3,05 п.п. |
| Снижение по всем назначенным, крайние исходы пропусков | +3,47 п.п. | −1,24…+3,47 п.п. |
| Инференциальная оценка, внешний интервал чувствительности | +1,43…+5,52 п.п. | −3,47…+5,52 п.п. |

В контрольной группе доля ограничений составила 204 / 1 700 = 12%. После исправления доля в пилотном плече лежит между 145 / 1 700 = 8,53% и (145 + 80) / 1 700 = 13,24%. Положительный знак разницы означает снижение частоты ограничений. Номинальный доверительный уровень оценок в крайних заполнениях — 95%, метод Ньюкомба. Внешний интервал показывает чувствительность к пропускам и выборочную неопределённость.

Порог заранее зафиксирован в плане. Для решения о пользе нижний сценарий по всем назначенным должен давать оценку снижения не менее 3 п.п., а нижняя граница интервала — быть выше нуля. Первоначальный срез проходит это правило. После сверки по оставшимся известным исходам оценка всё ещё выше 3 п.п., но правило по всем назначенным уже не пройдено. Ни направление эффекта, ни достижение цели надёжно не установлены.

Операции: 1 192 из 1 200 подтверждённых выполнены вовремя и правильно, 3 статуса неизвестны, 5 не соответствуют сроку или результату. Доля с полным знаменателем — 99,33%. Срез содержит нули по доступу после отзыва и двойному списанию. Это синтетическое допущение о зарегистрированных инцидентах. Одного зарегистрированного случая достаточно для рекомендуемой паузы. Проверка доли операций и пользы не снимает это требование.

### Что делать по результатам

1. **Аналитик и владелец расчётной системы, пять рабочих дней.** Сверить журнал ограничений и реестр распределения по исходным назначениям. Составить отчёт о количестве восстановленных и невосстановимых исходов по плечам. Для оставшихся пропусков повторить анализ чувствительности. Если восстановление невозможно, проверить сбор на новых семьях по заранее утверждённому плану. Порог и знаменатель прежней проверки сохраняются.
2. **Финансист, к повторному обсуждению.** Уточнить дополнительные прямые расходы и стоимость разработки на одинаковом горизонте. Наблюдать оплаченные месяцы по исходным группам, включая вышедших из семейного сценария. Учебный прогноз 279,105 млн ₽ относится к сценарию плана. В срезе Q2 нет затрат и данных об оплаченных месяцах для подтверждения вклада следующего охвата.
3. **Руководитель, после сверки.** Выбрать восстановление, новую проверку или остановку. При прохождении правила пользы, операций и экономики рассмотреть ограниченный охват с группой сравнения. До решения остаётся текущее обслуживание. В протоколе первая карточка сохранена в истории. Старое назначение «сверить итоги Q2» требует повторного согласования владельца.

Из исходного плана остаются [пять частей стратегии](strategy.md), [условный годовой прогноз](forecast.json), ограничения тарифа и правила согласия. Для проверки используйте [синтетические исходники](observations/reconciliation.md) и [журнал команд](demo-run/trace.json).
